# Stellar Bank

Stellar Bank is a premium banking website concept built as a full-stack demo with a secure dashboard, account summaries, transaction activity, and money transfers.

## Stack
- Backend: Node.js + Express
- Frontend: Plain HTML/CSS/JavaScript served by Express
- Auth: JWT with bcrypt hashing
- Data: JSON file persistence for demo purposes

## Features
- Premium landing page
- Register and login flow
- Secure account dashboard
- Account balances and card summary
- Internal money transfer workflow
- Transaction history
- Responsive UI for desktop and mobile
- Domain branding: `stellarbank.com`, `stellarbank.io`, `stellarbank.bank`

## Run locally
1. Install dependencies:
   `npm install`
2. Start the app:
   `npm start`
3. Open the site in a browser:
   `http://localhost:3000`
